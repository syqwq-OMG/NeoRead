# 原文摘录、区域截图和批注工具栏

右上角「设置 → 阅读 → PDF 批注工具栏」可选择独立工具栏或悬浮菜单球，以及上、下、左、右吸附。工具栏内的位置按钮也能调整吸附位置。设置随书库偏好保存，默认顶部居中。

选择「高亮」或「下划线」后选中文字即可标记；「选择文字」恢复普通选择。在原文和对照模式中选择「矩形框选」，拖出区域后保存荧光色边框。右键区域可复制截图、添加截图到笔记或删除矩形批注。文字选区提供「复制摘录」和「添加到笔记」；复制摘录后在论文笔记中粘贴，会同时保留摘录和来源链接。

笔记中的「第 … 页 · 原文」或 EPUB 位置链接支持鼠标和键盘 Enter 返回原文。当前文档的链接保持笔记页签打开；其他文档的链接使用书库的文档导航。被删除的批注会提示无法定位，但笔记内容和已有截图仍保留。

## 截图存储

- 原文图片由 PDF.js 从矢量页面渲染，不截取整个应用窗口；只接受最多 8 MiB、800 万像素的 PNG。
- 文件位置为 `<书库目录>/note-assets/<论文 ID>/<批注 ID>.png`，每篇论文独立目录；与书库一起备份或迁移，不写入临时下载目录和 PDF 解析缓存。
- Markdown 保存 `neoread-note-image://<论文 ID>/<批注 ID>`，不写入端口、认证 token 或本机绝对路径。编辑器仅加载校验后的本地截图引用，外部图片仍保持不自动加载。
- 删除矩形批注时暂留截图，因为笔记或撤销操作仍可能引用；移入回收站也保留。永久删除论文后清理该论文的截图目录。请通过应用删除论文，不手工清空截图目录。
- 合并文档并采用其他版本的笔记时，将其截图复制到保留版本的目录，并改写图片引用；原副本保留供回收站恢复。原文定位仍属于被引用的原始文档，不伪造不同 PDF 版本间的位置映射。
- 截图写入失败时保留矩形批注，右键复制或添加到笔记会重试生成。笔记读取失败时不会用新摘录覆盖旧笔记。

## 人工检查

1. 打开含正文和图片的 PDF，在四种吸附位置与悬浮球间切换，确认不越出阅读区域；重启后确认设置保留。
2. 高亮、下划线各标记一段，再切回选择工具；检查原文与译文的定位和撤销。
3. 在原文页面正向、反向拖拽矩形，右键复制到论文笔记；确认图片与来源链接，点击链接回到区域。缩放后仍能右键同一区域。
4. 从 PDF 或 EPUB 复制文字摘录，在笔记的编辑模式、源码模式分别粘贴，确认正文与位置链接保留。
5. 在 Agent 聊天中向上浏览，切到笔记再返回；阅读位置应恢复。继续运行的回答只在原来跟随底部时继续跟随。
6. 截图插入笔记后删除其矩形批注，确认图片仍在；移入回收站并恢复后确认可用，永久删除后确认对应截图目录被清理。
